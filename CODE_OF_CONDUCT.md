# Code of conduct

## Expected behavior

- Communicate with respect.
- Give technical feedback about the work, not the person.
- State assumptions and evidence.
- Protect private data and credentials.
- Accept correction when new test results contradict an earlier estimate.

## Unacceptable behavior

- Harassment or discrimination
- Threats
- Publication of private information
- Deliberate credential exposure
- Misrepresentation of estimates as measured facts
- Use of voice-cloning functions without authorization

## Enforcement

Report conduct concerns to the repository owner through a private GitHub channel. The repository owner can edit, reject, or remove contributions that violate this policy.
